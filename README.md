# Password-Cracking-and-Hash-Analysis-WK3
A hand-on cybersecurity project exploring password cracking and hash analysis using John the Ripper (JTR), Johnny GUI and Networkwalks online tools.


Password Cracking and Hash Analysis

Project Overview

This project focuses on understanding password security, password cracking techniques, and hash analysis using different cybersecurity tools.

Objectives

* Understand password hashing and authentication.
* Explore password-cracking techniques.
* Learn how hash calculation and verification work.
* Understand the importance of strong passwords.

Tools Used

1. John the Ripper (JtR) – Password-cracking tool.
2. Johnny GUI – Graphical interface for John the Ripper.
3. NetworkWalks Hash Calculator – Online hash calculation tool.
4. NetworkWalks Password Cracker – Online password-cracking tool.

Key Learnings

* Password hashing and hash analysis.
* Password recovery techniques.
* Practical exposure to cybersecurity tools.
* Importance of strong password policies.
